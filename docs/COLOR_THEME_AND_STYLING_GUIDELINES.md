# Color Theme and Styling Guidelines (Muted Purple)

## Core colors
| Name | Hex | Use |
|---|---|---|
| Deep Muted Purple | #51445F | Headers, primary buttons |
| Dusty Violet | #6B5B7E | Secondary buttons, voice assistant |
| Muted Purple | #81718F | Borders, icons, hover accents |
| Soft Lavender | #C3B5CC | Dividers, disabled states |
| Light Lavender | #E5DDEA | Table stripes, tinted panels |
| Lavender Mist | #F3EFF5 | Page background |
| Pure White | #FFFFFF | Cards, text on dark purple |
| Dark Plum | #30283A | Main body text |
| Grey Violet | #756B7C | Secondary text |
| Soft Grey Purple | #D9D1DF | Card borders |

## Status colors
| Status | Hex |
|---|---|
| Success | #4F8065 |
| Warning | #B88645 |
| Error | #B6535C |
| Information | #6889A7 |

## Rules
- Page background: Lavender Mist. Cards: white, 1px Soft Grey Purple border, subtle shadow.
- Primary buttons: Deep Muted Purple with white text. Secondary and voice: Dusty Violet.
- Text: Dark Plum. Secondary text: Grey Violet.
- Large touch targets: at least 56px high buttons, minimum 18px body text.
- Contrast: white text only on #51445F, #6B5B7E, and (to be verified) #4F8065 and #B6535C.
  Use Dark Plum text on tinted backgrounds for #81718F, Warning and Information.
- No gradients, minimal animation, no new brand colors.
- Fonts: Segoe UI / Noto Sans Devanagari so Hindi and English both fit.
- Always show a "DEMO - simulated data" banner.
